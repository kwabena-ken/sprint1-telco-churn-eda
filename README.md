# Sprint 1 — Telco Customer Churn EDA

Exploratory data analysis for the IBM Telco Customer Churn dataset.

## What is in this repo
- `sprint1_eda.ipynb` — cleaning and EDA notebook
- `telco_churn_cleaned.csv` — cleaned dataset

## Data
Source: IBM Telco Customer Churn  
Loaded from the official CSV URL in the notebook.

## Cleaning
- Converted `TotalCharges` to numeric
- 11 blank totals were new customers with tenure 0; filled with 0

## How to run
Open `sprint1_eda.ipynb` in Google Colab or Jupyter and run the cells from top to bottom.
